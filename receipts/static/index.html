    How it works

    1. Plan. A fast open model splits the question into sub-questions, each with a search query and a counter-evidence query that looks for disagreement or newer figures.
    2. Search. Tavily returns live pages with full text. Duplicates (same page, syndicated copies) are merged.
    3. Read. The model copies verbatim quotes from each page. A program checks every quote against the page text and throws away any it can't find.
    4. Audit coverage. A stronger model checks which sub-questions are thin, missing or contested and runs follow-up searches, or stops.
    5. Write. The answer is written one sentence at a time, each citing evidence ids. Facts and inferences are labelled separately.
    6. Fact-check and repair. A different model checks each sentence against only its cited quotes, and a rule checks that every figure appears in them. Failing sentences are narrowed or removed, and the removals are shown.

    All inference runs on open models on Nebius Token Factory; all search on Tavily. Web text is always passed as untrusted data, never as instructions.
